COMO CONFIGURAR GIT NO CESGA (non é necesario)

Débese crear unha clave SSH. Para comprobar se xa a hai: ls ~/.ssh
    - Para crear unha clave (se non hai): ssh-keygen -t ed25519 -C "correo_electrónico"

Copiar a clave pública: cat ~/.ssh/id_ed25519.pub

Ir a https://github.com/settings/keys. Pulsar New SSH key. Poñer un nome (CESGA) e pegar a clave copiada.

Probar a conexión: ssh -T git@github.com. Debe saír algo como 'Hi user! You've successfully authenticated, but GitHub does not provide shell access.'

Clonar o repositorio de GIT: git clone git@github.com:samuelgtrz/Proyecto-Integrador-de-IA.git

COMO CREAR UN ENTORNO MINICONDA COMPATIBLE CON YOLO

Para limpar os módulos precargados: module purge

Para cargar o módulo de Miniconda cunha versión de Python que soporte Yolo: module --ignore-cache load cesga/system miniconda3/22.11.1-1

Crear un entorno conda con Python 3.9 no directorio $STORE: conda create -p /mnt/netapp2/Store_uni/home/usc/cursos/curso1278/yolov8_env python=3.9 -y

Para activar o entorno: conda activate /mnt/netapp2/Store_uni/home/usc/cursos/curso1278/yolov8_env
    - Para instalar ultralytics (desde dentro do anterior entorno, só unha vez): pip install ultralytics. Agora poderemos utilizar comandos yolo.

COMANDOS DE XESTIÓN DOS ENTORNOS DE CONDA
Para desactivar o entorno: conda deactivate

Para eliminar o entorno: conda remove -n yolov8_env --all

COMO LANZAR UN NOTEBOOK NO CESGA

Para pedir un nodo con GPU e 16GB de memoria: compute --gpu --mem 16G

Limpar os módulos precargados: module purge

Cargar o módulo de Miniconda: module load cesga/system miniconda3

Activar o entorno: conda activate /mnt/netapp2/Store_uni/home/usc/cursos/curso1278/teclin/teclin_env
    - Para instalar notebook e jupyter (desde dentro do anterior entorno, só unha vez): pip install notebook. Agora poderemos utilizar sesións con notebooks.

Lanzar un notebook no nodo con GPU: jupyter notebook --no-browser --ip=$(hostname -i)

COMANDOS DE XESTIÓN XERAL DO CESGA

Para conectarse ao CESGA: ssh -o MACs=hmac-sha2-512 curso1278@ft3.cesga.es

Para subir un arquivo ao CESGA: scp -o MACs=hmac-sha2-512 "nome_arquivo" curso1278@ft3.cesga.es:/ruta/á/carpeta

Para subir un arquivo ao directorio $STORE: scp -o MACs=hmac-sha2-512 "nome_arquivo" curso1278@ft3.cesga.es:/mnt/netapp2/Store_uni/home/usc/cursos/curso1278/

Para descomprimir un zip no CESGA: unzip -o "nome_arquivo"

Para comprimir unha carpeta no CESGA: zip -r "nome_carpeta".zip /ruta/á/carpeta

Para descargar un arquivo do CESGA: scp -o MACs=hmac-sha2-512 curso1278@ft3.cesga.es:/mnt/netapp2/Store_uni/home/usc/cursos/curso1278/"nome_arquivo" .

Para añadir un arquivo a GIT: git add "nome_arquivo"; git commit -m "explicación"; git push

Para comprobar o tamaño dunha carpeta: du -sh /ruta/á/carpeta

Para comprobar o tamaño dun arquivo: ls -lh "nome_arquivo"

Para comprobar se temos acceso a GPU: srun --partition=medium --gres=gpu:a100:1 --nodes=1 --ntasks-per-node=32 --mem=128G --time=00:01:00 --test-only

Para recuperar con GIT unha carpeta eliminada: git checkout origin/main -- "nombre_carpeta"

Para conceder permisos sobre carpetas que dan problemas: chmod -R u+w /ruta/á/carpeta 

Recargar o servidor do CESGA: source ~/.bashrc
