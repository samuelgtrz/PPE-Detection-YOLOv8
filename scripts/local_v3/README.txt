This folder contains the neccesary files to run an example of the full project.

To execute it just run simulacion.py, select a PDF when you are requested to do so, and use tkinter windows to pick one of the areas in the working zone. The model will try to find the PPE's that appear in the specified area in the selected PDF.

**To run this, you will need to use your own API KEY in order to access to the Gemini model that processes the PDF to convert it into a JSON file that can be used more efficiently.
